# What You Need, How to Get It

This website can be used in a passive or an active mode. 

_Passive mode_ means that you can simply read the website's content, while _active mode_ means that you use the content as a tutorial to follow along with. 

To use the website in active mode, you will need a Git installation and a GitHub account. Instructions to install Git are available on the official website at [this](https://git-scm.com/) link, while a GitHub account can be created easily from the [GitHub homepage](https://github.com/). Once you have a Git installation and a GitHub account, you can jump to the next section ([What is Git, and Why?](1-why-git.md)) and follow along the tutorial.
