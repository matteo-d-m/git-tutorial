# Git & GitHub Basics: A Beginner's Guide to Version Control

This repository contains the raw files an introductory tutorial on Git and GitHub.

The tutorial is available at the following link: [Git & GitHub Basics](https://matteo-d-m.github.io/git-tutorial/).

The target audience are absolute beginners that want to get started with version control to serve basic scientific purposes.

## :exclamation: Requirements

To follow along the tutorial and start doing version control, users will need a Git installation and a GitHub account. 

The instructions to install Git are available on the official website at [this](https://git-scm.com/) link. A GitHub account can be created from the [GitHub homepage](https://github.com/).
